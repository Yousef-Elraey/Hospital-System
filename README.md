# 🏥 Hospital Management System

A backend RESTful API built using Java and Spring Boot to manage hospital operations efficiently.

## 🚀 Features: 
- Manage patients, doctors, and appointments
- RESTful APIs for all operations
- CRUD functionality for all entities
- Database integration using MySQL
- Structured backend architecture using Spring Boot

## 🛠️ Tech Stack:
- Java
- Spring Boot
- MySQL
- Hibernate (JPA)
- REST APIs

## 📌 System Modules:
- Patient Management
- Doctor Management
- Appointment Scheduling

## ▶️ How to Run:
1. Clone the repository:
   ```bash
   git clone https://github.com/Yousef-Elraey/Hospital-System.git
  2. Open the project in IntelliJ IDEA
  3. Configure MySQL database
  4. Run the application
